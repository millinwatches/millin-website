
  # Digital Maison Experience

  This is a code bundle for Digital Maison Experience. The original project is available at https://www.figma.com/design/IxBG3qsUrQIEWmHnY9qROT/Digital-Maison-Experience.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  

## Cloudflare Pages deployment

The v5 static site package is stored in the repository root. Cloudflare Pages unpacks `MAISON_MILLIN_JOURNAL_WITH_CORRESPONDENCE_BACKEND_v5 (3).zip` into `dist` during the deployment build.
